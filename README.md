# Araç Gider Takip

Flutter ile geliştirilmiş araç gider, bakım ve yakıt yönetim uygulaması.

## Özellikler

### Yakıt Yönetimi
- Benzin ve LPG desteği
- Yakıt maliyet takibi
- Tüketim hesaplama
- Ortalama tüketim analizleri
- Kilometre bazlı raporlama

### Gider Yönetimi
- Yakıt giderleri
- Bakım giderleri
- Sigorta giderleri
- Kasko giderleri
- MTV giderleri
- Diğer araç masrafları

### Bakım Takibi
- Çoklu bakım kalemi desteği
- Kilometre bazlı hatırlatmalar
- Tarih bazlı hatırlatmalar
- Bakım geçmişi görüntüleme
- Yaklaşan işlemler takibi

### Evrak ve Belge Yönetimi
- Fiş ve evrak görseli ekleme
- OCR ile fiş okuma
- Google Drive yedekleme
- Belge arşivleme

### Bulut Senkronizasyonu
- Firebase Authentication
- Cloud Firestore
- Google Drive entegrasyonu

## Teknolojiler

- Flutter
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Google Drive API
- Provider
